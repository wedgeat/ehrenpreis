HARDWARE
Ehrenpreis Electronic Chime Module

This folder contains the hardware design files for the Ehrenpreis electronic chime module, built around the NXP LPC802 microcontroller.

The hardware is developed specifically for this project and forms the physical foundation of the electronic chime.

For an overview of the project and the development process, see the blog post on wedge.at.

See the repository root for general project information and licensing.
