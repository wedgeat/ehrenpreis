FIRMWARE
Ehrenpreis Electronic Chime Module

This folder contains the embedded firmware for the Ehrenpreis electronic chime module, which uses the NXP LPC802 microcontroller.

The firmware is currently a work in progress and has not yet been completed. Implementation and documentation are therefore subject to change.

The intention is to provide the software responsible for controlling the electronic chime and its hardware.

For an overview of the project and its development process, see the blog post on wedge.at.
