EHRENPREIS
Electronic Chime Module

Ehrenpreis is an electronic chime module based on the NXP LPC802 microcontroller. The project combines custom hardware design and embedded firmware to create a dedicated electronic chime.

The repository is organised into two parts:

- hardware/ – Hardware design files for the electronic chime module.
- firmware/ – Embedded firmware for the LPC802 microcontroller.

The project explores the process of designing a custom electronic device, from hardware development to low-level microcontroller programming.

A blog post on wedge.at documents the development process and the decisions behind the project.
